# NBA Scoring Analysis — 2024-25 Season

## Project Overview

This project analyzes NBA player game data from the 2024-25 season to determine which players averaged the most points per game.

The analysis was completed using Python and the pandas data analysis library.

## Question

Which NBA players averaged the most points per game during the 2024-25 season?

## Dataset

The dataset contains individual NBA player game performances from the 2024-25 season, including statistics such as points, assists, rebounds, shooting percentages, turnovers, and minutes played.

## Method

Using Python and pandas, I:

1. Loaded the NBA dataset from a CSV file.
2. Grouped the game data by player.
3. Calculated each player's average points per game.
4. Sorted the results from highest to lowest.
5. Displayed the top 10 scoring averages.

## Result

Shai Gilgeous-Alexander had the highest scoring average in the dataset at approximately **31.93 points per game**.
